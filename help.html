1 접속 · 소속국 선택

  1. 브라우저(휴대폰·PC 모두 가능)에서 앱 주소를 엽니다.
  2. 처음 열면 PIN 입력 화면 → 팀 공용 PIN 7590 입력. 한 번 입력하면 그 기기에서는 다음부터 자동 통과됩니다.
  3. 상단바 왼쪽 소속국에서 본인 국을 고릅니다 (본사·부산·울산·창원·진주·대구·안동·포항·광주·목포·순천·전주·대전·청주·충주·춘천·강릉·원주·제주).
  4. 국을 고르면 그 국의 송신소로 시설칸이 자동으로 바뀝니다. (예: 대전 → 계룡산·식장산·흑성산·원효봉)
💡 자주 쓰면 즐겨찾기에 등록하세요. 선택한 소속국은 기기에 기억됩니다.

2 화면 구성

왼쪽 사이드바

  • 진행률(예: 3/8 시설 작성)과 시설 목록이 보입니다. 작성한 칸은 초록 점, 작성 중은 주황 점.
  • 시설 이름을 클릭하면 그 시설칸만 크게 나타납니다 → 집중해서 작성.
  • 맨 위 ≡ 전체 보기를 누르면 모든 시설칸을 한 번에 볼 수 있어요 (검토·다운로드 전 확인용).

사이드바 아래 — 저장 · 다운로드

  • 💾 저장 버튼과 📄 한글 다운로드(이 날 하루 / 한달)가 사이드바 맨 아래에 있습니다.

상단바 오른쪽

  • 🔍 검색 지난 일지 검색 · 🔧 정비사례입력 고장·정비 사례 · 📖 사용법 · 🌙 밝게/어둡게.
🌙 다크 모드: 상단바의 🌙(밝을 때) / ☀️(어두울 때)를 누르면 화면이 어둡게/밝게 바뀝니다. 선택은 기기에 기억돼요.

📱 휴대폰에서는 위에서 아래로 진행률 → 시설 목록(좌우로 넘김) → 작성칸 → 저장·다운로드 순서로 보입니다.

3 일지 작성

날짜 · 날씨

  • 날짜를 선택하면 요일이 자동으로 채워집니다.
  • 날씨는 직접 입력 (예: 맑음, 흐림, 비).

시설별 내용

  • 공통 칸(송출기술 · TVR/AM) + 소속국 송신소 칸 + 공통 칸(민원사항 · 특기사항)에 각각 입력합니다.
  • 여러 줄 입력 가능 (Enter로 줄바꿈).
  • 내용을 안 적은 칸은 문서에 ◎ 표시만 나옵니다.
◎ 계룡산(송) 주간정비 실시 1. 송신기#2 더미로드 시험 양호 2. STL 점검 정상

4 사진 넣기

올리기

  1. 각 시설칸의 📷 사진 영역에 드래그하거나 눌러서 사진을 올립니다 (여러 장 가능).
  2. 올리면 자동으로 용량이 압축되고 사진1, 사진2… 번호가 붙습니다.
  3. 썸네일 아래 "사진 설명" 칸에 설명을 적으면 문서에서 사진 밑에 들어갑니다.

사진 위치 (2가지)

  • 그냥 두면 → 내용 텍스트 아래에 자동으로 붙습니다 (한 줄에 4장).
  • 내용 중간에 넣으려면 → 텍스트에 [사진1] 처럼 적으세요.
작업 전 상태 점검 [사진1] 작업 후 완료 확인 [사진2,3]

→ "작업 전…" 아래 사진1, "작업 후…" 아래 사진2·3이 들어갑니다. ([사진1,2] 처럼 쉼표로 여러 장)

💡 사진은 각각 테두리 박스 + 설명칸으로 예쁘게 들어갑니다. 4장 넘으면 다음 줄로.

5 저장

  • 입력하면 1.5초 뒤 자동 저장됩니다 (사이드바 저장 버튼 아래 "💾 자동 저장됨" 표시).
  • 따로 저장 버튼을 안 눌러도 내용이 사라지지 않아요. 즉시 저장하려면 💾 저장 버튼.
  • 저장된 내용은 다른 기기(집·사무실·휴대폰)에서도 같은 소속국·날짜를 열면 이어서 볼 수 있어요.
  • 날짜를 바꾸면 그 날짜 내용으로 화면이 바뀌고, 이전 내용은 저장됩니다.
  • ⚠️ 오늘이 아닌 날짜(과거·미래)에 작성 중이면 날짜 위에 노란 경고가 표시됩니다 — 실수 방지용.

6 한글파일 다운로드

사이드바 맨 아래 📄 한글 다운로드에서:

구분방법결과
하루이 날 하루 버튼그날 일지 1장 (사진 포함)
한달월 선택 후 한달 버튼그 달 저장분 전체가 한 파일에
  • 다운로드한 .hwpx 파일은 한글에서 바로 열립니다.
  • 필요하면 한글에서 "다른 이름으로 저장 → .hwp"로 저장하세요.

7 고장 · 정비 사례

  • 상단바 🔧 정비사례입력을 누르면 전국 공용 고장·정비 사례 페이지로 이동합니다.
  • 고장난 장비의 모델명 · 증상 · 조치를 등록해 두면, 다른 국에서도 검색해서 참고할 수 있어요 (전국 지식 공유).
  • 등록한 사례는 표준 장애보고서(.hwpx)로 사진과 함께 다운로드됩니다.
💡 반복되는 고장·해결법을 남겨두면 팀 전체가 시간을 아낍니다.

8 꼭 알아둘 점

  • ✅ 각자 자기 담당 시설만 작성하면 됩니다. 여러 명이 같은 날짜를 동시에 써도 자기가 쓴 칸만 저장되어 서로 덮어쓰지 않아요.
  • 💡 다른 담당자가 방금 저장한 내용을 화면에서 보려면 새로고침하세요.
  • ⚠️ 단, 같은 시설칸을 두 명이 동시에 고치면 나중에 저장한 사람 것으로 남아요. 담당이 겹치는 칸은 조율하세요.
  • 🗑️ 6개월 지난 일지는 자동으로 삭제됩니다. 보관이 필요하면 한글파일로 다운로드해서 공유폴더 등에 저장하세요. (다운로드한 파일이 영구 보관본)

9 문제 해결

화면이 이상하거나 예전 버전이 보여요

강력 새로고침: Ctrl + Shift + R (휴대폰은 주소를 다시 입력하거나 앱 방문 기록 새로고침).

페이지가 아예 안 열려요

회사 내부망이 막았을 수 있어요. 휴대폰 데이터(핫스팟)로 접속되면 회사망 차단입니다 → 전산 담당에게 문의.

사진이 안 올라가요 / "올리는중…"에서 멈춰요

사진 저장소 설정 문제일 수 있어요. 관리자에게 알려주세요.

저장이 안 돼요 (오류 메시지)

화면의 빨간 오류 메시지를 캡처해서 관리자에게 전달해 주세요.

관리자 문의 시, 상태 메시지나 오류 내용을 함께 알려주시면 빠르게 해결됩니다.
