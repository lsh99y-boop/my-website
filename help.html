1 접속하기

  1. 브라우저에서 앱 주소를 엽니다.
  2. 처음 열면 PIN 입력 화면이 나옵니다 → 팀 공용 PIN 7590 입력.
  3. 한 번 입력하면 그 PC에서는 다음부터 자동 통과됩니다.
💡 자주 쓰는 PC라면 즐겨찾기에 등록해 두세요.

2 일지 작성

날짜·날씨

  • 날짜를 선택하면 요일이 자동으로 채워집니다.
  • 날씨는 직접 입력 (예: 맑음, 흐림, 비).

시설별 내용

  • 송출기술 · TVR/AM · 계룡산 · 식장산 · 흑성산 · 원효봉 · 민원사항 · 특기사항 칸에 각각 입력합니다.
  • 여러 줄 입력 가능 (Enter로 줄바꿈).
  • 내용을 안 적은 칸은 문서에 ◎ 표시만 나옵니다.
◎ 대덕(송) 주간정비 실시 1. 송신기#2 더미로드 시험 양호 2. STL 점검 정상

3 사진 넣기

올리기

  1. 각 시설칸의 📷 사진 → 파일 선택으로 사진을 올립니다 (여러 장 가능).
  2. 올리면 자동으로 용량이 압축되고 사진1, 사진2… 번호가 붙습니다.
  3. 썸네일 아래 "사진 설명" 칸에 설명을 적으면 문서에서 사진 밑에 들어갑니다.

사진 위치 (2가지)

  • 그냥 두면 → 내용 텍스트 아래에 자동으로 붙습니다 (한 줄에 4장).
  • 내용 중간에 넣으려면 → 텍스트에 [사진1] 처럼 적으세요.
작업 전 상태 점검 [사진1] 작업 후 완료 확인 [사진2,3]

→ "작업 전…" 아래 사진1, "작업 후…" 아래 사진2·3이 들어갑니다. ([사진1,2] 처럼 쉼표로 여러 장)

💡 사진은 각각 테두리 박스 + 설명칸으로 예쁘게 들어갑니다. 4장 넘으면 다음 줄로.

4 저장

  • 입력하면 1.5초 뒤 자동 저장됩니다 (화면 아래 "💾 자동 저장됨" 표시).
  • 따로 저장 버튼을 안 눌러도 내용이 사라지지 않아요.
  • 저장된 내용은 다른 PC(집·사무실)에서도 같은 날짜를 열면 이어서 볼 수 있어요.
  • 날짜를 바꾸면 그 날짜 내용으로 화면이 바뀌고, 이전 내용은 저장됩니다.
  • ⚠️ 오늘이 아닌 날짜(과거·미래)에 저장할 때는 "이 날짜가 맞습니까?" 확인창이 떠요. 실수로 다른 날짜에 쓰는 것을 막기 위해서예요. (날짜 위에 노란 경고도 표시됨)

5 한글파일 다운로드

구분방법결과
하루치아래 "한글파일 다운로드" 버튼그날 일지 1장 (사진 포함)
한 달치맨 아래 📅 한 달치 다운로드 → 월 선택 → 버튼그 달 저장분 전체가 한 파일에
  • 다운로드한 .hwpx 파일은 한글에서 바로 열립니다.
  • 한글에서 열어 필요하면 "다른 이름으로 저장 → .hwp"로 저장하세요.

6 꼭 알아둘 점

  • ✅ 각자 자기 담당 시설만 작성하면 됩니다. 여러 명이 같은 날짜를 동시에 써도 자기가 쓴 칸만 저장되어 서로 덮어쓰지 않아요.
  • 💡 다른 담당자가 방금 저장한 내용을 화면에서 보려면 새로고침하세요. (저장은 항상 안전하게 병합되지만, 화면은 열었을 때 기준으로 보입니다)
  • ⚠️ 단, 같은 시설칸을 두 명이 동시에 고치면 나중에 저장한 사람 것으로 남아요. 담당이 겹치는 칸은 조율하세요.
  • 🗑️ 6개월 지난 일지는 자동으로 삭제됩니다. 보관이 필요하면 한글파일로 다운로드해서 공유폴더 등에 저장하세요. (다운로드한 파일이 영구 보관본)

7 문제 해결

화면이 이상하거나 예전 버전이 보여요

강력 새로고침: Ctrl + Shift + R

페이지가 아예 안 열려요

회사 내부망이 막았을 수 있어요. 휴대폰 데이터(핫스팟)로 접속되면 회사망 차단입니다 → 전산 담당에게 문의.

사진이 안 올라가요 / "올리는중…"에서 멈춰요

사진 저장소 설정 문제일 수 있어요. 관리자에게 알려주세요.

저장이 안 돼요 (오류 메시지)

화면 아래 빨간 오류 메시지를 캡처해서 관리자에게 전달해 주세요.

관리자 문의 시, 화면 아래 상태 메시지나 오류 내용을 함께 알려주시면 빠르게 해결됩니다.
